# 手順書4：本番切替後の確認とロリポップ解約

本番切替後の動作確認と、旧サーバー（ロリポップ）の解約手順です。
所要時間：確認 30分 ／ 解約手続き 15分 ／ 猶予期間 1〜2週間

---

## Step 1: 本番動作を徹底的に確認

新サイトが `https://research.takagiryoko.com` で表示されるようになったら、以下を全て確認：

### 表示・機能確認
- [ ] トップページ全体が正常表示（レイアウト崩れなし）
- [ ] スクロール進捗バーが動く
- [ ] ヘッダーがスクロールで隠れ、上スクロールで再表示
- [ ] 現在のセクションのナビ項目に下線が入る
- [ ] インタビュー項目にアクセントブラウンの●が付いている
- [ ] モバイルサイズ（DevTools のレスポンシブモード）で三本線メニューが動く
- [ ] 三本線メニューを開いてリンクをクリックしたら閉じる

### ニュース関連
- [ ] トップページのニュースにピン留め 2件 + 最新 5件が表示
- [ ] カテゴリフィルタ（すべて／論文／学会発表／...）が動く
- [ ] 「その他の◯◯を見る」リンクがカテゴリごとに正しい URL に飛ぶ
- [ ] `/news.html` にアクセスで全ニュースが年別に表示
- [ ] `/news.html?filter=media` などで自動絞り込み
- [ ] 各ニュースの外部リンクアイコンが正しく動く

### 言語切替
- [ ] JP/EN トグルで表示が切り替わる
- [ ] `?lang=en` で英語で開く
- [ ] `?lang=ja` で日本語で開く

### インタビュー・その他ページ
- [ ] `/interview-selfai.html` が正常表示
- [ ] `/interview-burial.html` が正常表示
- [ ] `/interview-selfai.html?lang=en` で英語切替（ただしこれらは静的HTMLのため一部機能に差異あり）

### フォーム
- [ ] お問い合わせフォームが表示される
- [ ] 実際にテスト送信して、Formspree にメールが届くか確認

### メタ情報・SEO
- [ ] ページ HTML の `<title>` が正しい
- [ ] `<meta name="description">` が正しい
- [ ] OG 画像がついている（TwitterやX で URL を貼って確認）
- [ ] 構造化データ（JSON-LD）が入っている（Google Rich Results Test で検証可能）

---

## Step 2: 旧サーバー（ロリポップ）のバックアップ

**解約前に必ずバックアップを取ってください。**

1. ロリポップの管理画面にログイン
2. FTP 設定を確認、または FTP ソフト（FileZilla、Cyberduck 等）で接続
3. `/public_html/` 配下のファイル全てをローカルにダウンロード
4. ダウンロードしたフォルダを **iCloud Drive の research フォルダ内に「archive-lolipop-YYYYMMDD」** という名前で保存

---

## Step 3: Google Search Console の設定確認

1. https://search.google.com/search-console にアクセス
2. `research.takagiryoko.com` プロパティを開く
3. 左メニュー「サイトマップ」を選択
4. 現在登録されているサイトマップの URL を確認（`/sitemap.xml` のはず）
5. 「削除」→ 再度「新しいサイトマップの追加」で `sitemap.xml` を再送信
6. 「URL 検査」で `https://research.takagiryoko.com/` と `https://research.takagiryoko.com/news.html` の インデックス状況を確認

---

## Step 4: 1〜2 週間の観察期間

すぐには解約せず、以下を観察：

- [ ] Cloudflare Pages の「Analytics」でアクセスが来ているか
- [ ] Google Search Console でクロールエラーが出ていないか
- [ ] 誰かからの「サイトが見えない」報告がないか

問題なければ次に進む。

---

## Step 5: ロリポップの解約

⚠️ **契約期間に注意**。次回更新月の1〜2ヶ月前に手続きするのが理想。

1. ロリポップ管理画面 → 「契約・お支払い」→ 「解約手続き」
2. 案内に従って解約フォームを記入
3. 解約理由に「サイトを他サーバーに移行したため」と記載
4. 解約完了メールを保管

### 解約タイミング
- 契約期間の途中で解約しても、期間終了までは使える（料金返金なし）
- 期間終了時に自動的にサイトが消える
- 万が一に備えて、期間終了の1週間前に FTP でもう一度バックアップを取る

---

## Step 6: 移行完了の記録

このプロジェクトのマイグレーション記録として、以下を残しておく：

- 移行日：
- 旧サーバー：ロリポップ（`YYYYMMDD` に解約）
- 新サーバー：Cloudflare Pages
- ドメイン：ムームードメイン（`research.takagiryoko.com` は Cloudflare へ CNAME）
- リポジトリ：https://github.com/takagi-ryoko/research-takagiryoko-com

---

## トラブル対応：もし新サイトに問題が出たら

### 一時的にロリポップに戻す方法（切替直後の緊急対応）

1. ムームードメインの DNS 設定を開く
2. `research` の CNAME レコードを削除
3. 代わりに元の A レコード（ロリポップの IP アドレス）を追加
4. 数分〜数十分でロリポップ側の旧サイトが表示される

### 長期的に問題を修正する場合

- 新サイト側で問題を修正 → GitHub にプッシュ → Cloudflare が自動再デプロイ
- DNS 変更は不要
